# Changelog

## 1.2.0

### Added

- Language option for the mod's own text: English (default), Italian, Spanish
  and Portuguese. Reachable from the mod's options and from the in-game
  OPTION menu (MOVE INFO LANG).
- Third page in the move-select box: a short description of the effect.

## 1.1.0

### Added

- Short description page for the highlighted move.

## 1.0.0

### Added

- Damage range for the highlighted move, computed with the cart's own damage
  calculator at the lowest and highest random roll.
- Power, accuracy and type multiplier page.
- SELECT explanation box with the numbers and the percentage of the foe's HP.
